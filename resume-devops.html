Проекты

TaskHub — сервис на FastAPI в Docker Compose Docker · PostgreSQL · Redis · Celery
  • Compose-файл на шесть сервисов: postgres, redis, mailpit, api, worker, beat; у каждого свой healthcheck, API и воркеры стартуют только после готовности БД и брокера через depends_on: condition: service_healthy.
  • Данные не теряются между запусками: именованные тома pgdata и redisdata, у БД и брокера restart: unless-stopped.
  • Dockerfile многостадийный: в сборщике остаётся toolchain и кеш wheels, в рантайм попадают только virtualenv и приложение, сервис работает от непривилегированного пользователя; слой зависимостей пересобирается отдельно от кода.
  • Вся конфигурация во внешнем файле: строки подключения, брокер, секрет, флаги логирования; запуск — docker run --env-file .env, без правок в коде.
Сборка релиза Android-игры PowerShell · AAB / APK · SHA-256
  • Скрипт собирает пакеты одной командой, подписывает их ключом и считает SHA-256 каждого артефакта, версии и контрольные суммы пишет рядом с ними.
  • Ключ хранится отдельно от исходников и переживает пересборку: release не должен зависеть от того, на какой машине собрали.
  • Описание релиза и контрольные суммы лежат в репозитории вместе с артефактами — видно, что именно уходило в выкатку.
Anime DB — каталог из 3 публичных API Actix-Web · SQLite FTS5 · Docker
  • Сборка в контейнере, каталог на ~20 тыс. записей пересобирается по расписанию, ручной перезапуск защищён токеном.
  • 564 юнит-теста; CI на каждом пуше: rustfmt, clippy с -D warnings, cargo test — сборка ломается на ошибках и предупреждениях.
