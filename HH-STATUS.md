## Грабли, на которые я наступил (чтобы не повторять)

- **Видимость резюме не сохраняется кликом по карточке.** Клик открывает страницу
  `/resume/<id>/visibility`, там нужно выбрать вариант и нажать
  `[data-qa="resume-partial-edit-save"]`. Без «Сохранить» настройка откатывается —
  я так потерял два круга и проверил, что «видно всем» не применилось.
- `/resume/<id>/visibility` при прямой навигации отдаёт 404, существует только как
  клиентский маршрут после клика по карточке.
- Месяцы в форме опыта — не `<input>`: `[data-qa="magritte-select-activator"]`,
  варианты `[data-qa="magritte-select-option-NN"]` (Ноябрь = 11, Февраль = 2).
- Год окончания заблокирован, пока включена галочка «Работаю сейчас».
- `/resume/<id>/about` и `/profile/block/about` не существуют (404).
- Поиск вакансий парсится через `fetch` (страница отдаётся SSR), а страница вакансии
  по `fetch` отдаёт только SPA-оболочку — её нужно открывать настоящей навигацией.
- `browser.evaluate` сразу после клика по ссылке может упасть («target navigated»):
  нужен ретрай. Скрипт внутри страницы должен ждать элемент через poll.
