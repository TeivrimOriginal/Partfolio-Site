# Где тебя возьмут с маленьким опытом — 4 площадки (проверено 03.10.2026)

Проверял не из головы, а запросом по сайту. Что реально работает для джуна
без коммерческого опыта: **биржи заказов, где отбор идёт по скорости ответа и
portfolio-картинке, а не по стажу**. Ни одна из площадок ниже не смотрит на
«сколько лет опыта» — смотрит на скорость, цену и перфокартинку.

---

## 1. Kwork — kwork.ru — уже единственный сайт, который тебя взял

**Статус:** живой, профиль с 07.02.2024. Это не «список», это факт: клиент
зарегистрировался раньше тебя и уже платил (с 29.02.24).

| Что требует | Твой факт |
|---|---|
| Скорость ответа | до сих пор да, поэтому и живой профиль |
| Отклик на проект | 30/50 офферов в день — ты делал |
| Портфолио | 3 кворка по 400₽ опубликованы (TG-бот 55027998, парсер 55032921, REST API 55032385) |

**Доказательство, что фильтр там не по опыту:** кворк «Создам сайт под ключ»
(55032410) тебе заблокировали — требование **5 портфолио-работ**. Остальные три
прошли без единого отказа. То есть площадка берёт по счёту работ, а не по стажу.

Что делать: не публиковать новые кворки, а **отвечать на проекты быстрее всех**.
Рынок ИТ — 30 проектов/день, при 60+ откликах. Через 3 часа твой отклик
никто не читает. Твоё козырное отличие сейчас — Rust и C++ (на Kwork их почти
нет, все пишут на Python и PHP). Отвечай первым, даже на «модель транспорта за
99–200k».

## 2. FL.ru — fl.ru — самый высокий порог входа из бесплатных, деньги платят на карту

**Статус:** жив, 1500+ заказов в день. Проверено: правила для фрилансеров
читаются, там прямо написано, что для новичка **не нужно ничего платить**.

Что можно делать бесплатно (цитата с сайта):
- откликаться на заказы с опцией «для всех», отвечать на **любые вакансии**,
  участвовать в **любом конкурсе**;
- **Магазин услуг** — размещение бесплатное для всех фрилансеров, можно создать
  неограниченное количество услуг;
- попасть в **Каталог фрилансеров** и поиск — бесплатно, если указал
  специализацию в настройках профиля.

Платное (не брать на старте): пакет откликов на заказы «не для всех», PRO,
размещение в специализации.

Почему это лучший из бесплатных: есть **«Безопасная сделка»** — деньги
резервируются на платформе, арбитраж разбирает спор по переписке, физлицу
вывод **сразу на карту**. С твоим Kwork-опытом (ответ в 30 минут) ты тут
закроешь первый заказ за 2–3 дня.

Твой угол: категории **Инжиниринг, Автоматизация бизнеса, Игры, Mobile,
Мессенджеры, Крипто и блокчейн** — там конкуренция в разы ниже, чем в
«Программирование/Сайты», где сидят 500-откликовые страницы. Откликайся туда.

Порог: заполненный профиль + 2–3 работы в портфолио (ссылки на твой GitHub
подойдут) + отзывы. Портфолио набивается первым же заказом.

## 3. Weblancer — weblancer.net — живой, порог 0, сейчас 157 заказов

**Статус:** проверено сегодня — 157 заказов, даты 30.09–03.10.2026, все свежие.
Безопасная сделка, оплата в USDT/USDC.

Никакого теста, никакой подписки, никакого требования к портфолио в правилах
регистрации. Это самая низкая планка из четырёх.

Что там видно прямо сейчас по твоему стеку:
- «Доработка парсеров на Python» — 7 заявок;
- «Бот для авто выдачи робуксов» ($10, 10 заявок) — **это твой профиль**;
- «Оценить и завершить разработку системы AVENQ» ($500, аудит кода + интеграция
  API, 10 заявок) — тоже твой класс задач;
- «Flash USDT за $200000» — **это скам, не откликайся**, идеальный трек для
  кидалово. Не брать сделку вне безопасной сделки никогда.

Почему берут джуна: заказчик платит 10–60$ за мелочь, ему нужен тот, кто
ответит сейчас, а не лучший. Скорость + готовность сделать «как скажу» = заказ.

Осторожно: много заказов с «напишите отзывы / выполните задания по инструкции»
— это слив бюджета заказчика, деньги платят, но профиля не даёт. На них время
не тратить, брать только 1–3 таких, чтобы набить отзывы, и сразу идти в
«Доработка парсеров / боты / API».

## 4. Workzilla — work-zilla.com — берёт любого, но сначала купи доступ

**Статус:** жив, 892 000 исполнителей, 4 800 000 заданий, 75 835 заданий
выполнено за месяц. Вход для исполнителя — **три условия, все три обязательные**:
1. идентификация по паспорту,
2. **тесты** для получения доступа к заданиям,
3. **оплаченная подписка**.

То есть это единственная площадка из четырёх, где тебя не «возьмут бесплатно»
за регистрацию — нужен платный доступ. Деньги при этом реальные: заказчики
платят защищёнными платежами, отклик в среднем через 35 секунд после публикации.

Стоит ли: да, когда нужен быстрый входящий поток заданий, и только если
подписка окупается за 1–2 заказа (то есть да, при 500₽/заказ окупается за
2–3 выполненных). Порог по деньгам на старте — билет подписки, порог по опыту — ноль.

Плюс: живые категории под твой стек — «Разработка скрипта», «Парсинг данных
с сайта», «Telegram-боты», «Подключение и разработка API», «Разработка игр»,
«QA и аудит кода», «Инфраструктура и DevOps», «Разработка браузерных расширений».

## Порядок действий (то, что реально даст первый рубль)

| Шаг | Что | Сколько времени |
|---|---|---|
| 1 | **Weblancer** — регистрация + отклик на 10 заказов «парсеры/боты/API» | 1 час, бесплатно |
| 2 | **FL.ru** — профиль + 3 работы портфолио (ссылки GitHub) + 2 услуги в Магазин услуг + 15 откликов «для всех» | 1 вечер, бесплатно |
| 3 | **Kwork** — перестать отвечать на всё подряд, отвечать первым на проекты с ≤10 откликами, геймдев/тулинг/C++/Rust | уже делаешь |
| 4 | **Workzilla** — тесты, и только потом подписка | после первых денег с 1–3 |

Честный прогноз: Weblancer + FL.ru + Kwork при 15–25 точных откликах в день
дают 1–3 оплаченных мелких заказа за 7–14 дней. Это не оффер в компанию,
это деньги и первые отзывы, после которых в Kwork/FL перестают резать новичка
и берут уже «с отзывами». Дальше с отзывами идти на стажировки/вакансии.

## Чего не делать (проверено на своих ошибках)
- Не выкладывать «универсальные» кворки («сделаю сайт под ключ») — Kwork режет
  без 5 портфолио-работ. Каждый кворк = один конкретный результат.
- Не отвечать на отклик, где уже 60 откликов (3262618 TG-ИИ-бот — таких
  просмотренных не будет).
- Не брать заказы вне безопасной сделки/биржи — «Flash USDT $200000» на
  Weblancer это скам.
- Не распыляться на английские биржи: Upwork режет ботами (403 на проверку),
  английский у тебя пока только чтение — это заявка, а не сделка.
