## Как это сделано технически (на будущее)
1. Поиск через `fetch` на странице `/search/vacancy` — она отдаётся SSR, парсится.
   Страница вакансии по `fetch` отдаёт только SPA-оболочку, поэтому её нужно
   открывать настоящей навигацией.
2. Проверка на странице вакансии: `Опыт работы: не требуется` + `Формат работы: удалённо`
   + `Вы откликнулись` (уже откликался) — иначе скип.
3. Клик `[data-qa="vacancy-response-link-top"]` → переход на страницу отклика.
4. Клик `[data-qa="vacancy-response-submit-popup"]` → отправка.
5. Письмо: кнопка «Приложить сопроводительное письмо» →
   `textarea[data-qa="vacancy-response-popup-form-letter-input"]` →
   `[data-qa="vacancy-response-letter-submit"]`.
   В React-поля значение пишется через сеттер прототипа + событие `input`.
6. `browser.evaluate` сразу после клика по ссылке может упасть (навигация) —
   нужен ретрай, 4 попытки. И скрипт внутри страницы должен ждать появления
   кнопки через poll, а не сразу читать DOM.
