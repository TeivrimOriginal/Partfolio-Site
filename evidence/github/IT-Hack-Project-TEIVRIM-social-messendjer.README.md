как пользоваться - 
требования к запуску - у вас должно быть два устройства подключенных к одной сети.

шаг 1 - скачайте https://nodejs.org/en 
шаг 2 - скачайте репозиторий
шаг 3 - разархивируйте его и перейдите проводником в папку.
шаг 4 - в адресе папке введите CMD 
шаг 5 - введите * node server.js * 
шаг 6 - установите необходимые библиотеки с помощью команды npm install *название библиотеки*
шаг 7 - когда у вас запуститься сервер, введите указанный адрес в браузер на двух или более устройствах.

( если ваш браузер будет блокировать микрофон то перейдите по ссылке browser://flags/#unsafely-treat-insecure-origin-as-secure 
и в первом флаге вставьте ваш адрес, а параметр выберите Enable или Включить ( Это только для яндекс браузера ) )
