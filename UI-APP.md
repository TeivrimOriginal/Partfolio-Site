# Окно рассылки — ui-app.ps1

Настольное приложение с двумя вкладками: что отправлено и что пришло.

## Запуск

Двойной щелчок по `run-ui.cmd` из проводника. Либо:

```powershell
powershell -STA -ExecutionPolicy Bypass -File ui-app.ps1
```

Ключ `-STA` обязателен: WPF без однопоточной квартирации не открывается.
`run-ui.cmd` уже содержит этот ключ. Без него приложение не падает молча —
печатает подсказку и выходит с кодом 3.

## Что показывает

**Вкладка «Отправленные»** — таблица писем, новые сверху:

| Когда | Ящик | Кому | Компания | Тема | Статус |

Колонка «Ящик» вторая, потому что главный вопрос здесь — с какого адреса ушло
письмо и кому. Данные из `sent-log.csv`.

У старых писем (отправленных до появления колонки `from`) ящик честно
показан как «(ящик не указан)» и такая строка выглядит приглушённее. Пустой
ячейки не бывает: она выглядела бы как «письмо ушло неизвестно откуда».

**Вкладка «Полученные»** — живые ответы из `inbox-replies.csv`, который
заполняет `imap-read.ps1`. Пока ответов не было, показывается надпись
«Пока пусто», а не пустая таблица.

Под заголовками вкладок — количество строк. Сверху, под шапкой — строка
сводки: сколько писем с каждого ящика, сколько отправлено, сколько ошибок,
сколько ответов.

## Управление

- **F5** или кнопка «Обновить» — перечитать файлы
- автообновление раз в минуту
- **двойной клик по строке** — скопировать строку в буфер обмена
- сортировка по клику на заголовок колонки

## Проверка

```powershell
powershell -ExecutionPolicy Bypass -File test-ui-data.ps1   # 26 проверок, без GUI
powershell -ExecutionPolicy Bypass -File test-ui-app.ps1    # 22 проверки, окно не показывается
```

`test-ui-app.ps1` сам перезапускается с `-STA` и собирает окно без показа:
проверяет число вкладок, русские заголовки колонок, привязку «Ящик» к полю
`box`, совпадение строк с `sent-log.csv`, поведение надписи «Пока пусто» и
то, что в MTA приложение выходит с кодом 3.

## Устройство

- `ui-data.ps1` — слой данных: читает CSV, переводит статусы на русский,
  считает сводку по ящикам. Без интерфейса, поэтому и проверяется отдельно.
- `ui-app.ps1` — окно. Собрано кодом, а не из XAML: с XAML ошибка разметки
  видна только при запуске, то есть глазами.
- `run-ui.cmd` — запускалка. Файл намеренно без кириллицы: `cmd.exe` читает
  `.cmd` в кодовой странице OEM, а не в UTF-8, и русские комментарии
  превращаются в мусор, который cmd потом пытается выполнить.
