## Грабли PowerShell 5.1 (все воспроизведены, не выдуманы)
1. `.ps1` без UTF-8 BOM читается как ANSI → кириллица ломает парсер (ParserError).
   Любой новый .ps1 пересохранять: `[IO.File]::WriteAllText($p,$t,(New-Object Text.UTF8Encoding $true))`.
2. `-replace 'pat', 'текст' + $var` → `BadReplaceArgument`: парсер собирает
   `('pat','текст')` в МАССИВ. Любое выражение в замене оборачивать в скобки.
3. `"$var: текст"` → `InvalidVariableReferenceWithDrive` (двоеточие = имя диска).
   Лечится `"${var}: ..."` или `"{0}: ..." -f $var`.
4. Функция, возвращающая один элемент, схлопывается в скаляр → `scalar + array`
   превращается в склейку строки и весь список почт стал одной строкой. Лечится `@(...)`.
5. Имена переменных нечувствительны к регистру: локальная `$stats` затёрла параметр
   `[string]$Stats` → `Join-Path` получил пустой путь.
6. `Get-ChildItem`/`[IO.Directory]::Exists` против `Test-Path`: `Test-Path` дал
   ложноположительный true на несуществующей папке Thunderbird.
7. `Import-Csv` на файле без заголовка и `$obj += $x` на PSObject → op_Addition.
   Накопление через `New-Object System.Collections.ArrayList`.
8. Инлайновый `Parser::ParseFile($p,[ref]$null,[ref]$errs)` в `-Command` ломает разбор
   самой команды → проверка синтаксиса вынесена в `check-syntax.ps1`.
